External signal API

API key click reveal 
curl -X POST '/api/signals' \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: <your key>' \
  -d '{
    "pair": "XBTUSD",
    "action": "BUY",
    "confidence": 0.78,
    "source": "external",
    "origin": "my-bot",
    "reasoning": "Breakout above 4h resistance",
    "ttlMs": 600000,
    "weight": 1.0
  }'
  • action: BUY / SELL / HOLD
  • confidence: 0.0 – 1.0 (how sure you are)
  • weight: 0.0 – 2.0 (trust multiplier; defaults to source baseline)
  • ttlMs: how long the signal stays live (max 1 hour)
  • Signals are aggregated with technical + LLM signals before execution.
